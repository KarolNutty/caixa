Princípios

O token existe para ser trocado

Toda cor, canto e sombra vem de uma variável. O tema escuro não reescreve regra nenhuma: ele troca valores. Uma cor escrita direto numa regra é uma cor que o tema não alcança.

Contraste é medido, não estimado

Nenhuma cor entra na paleta sem passar por cálculo. A razão de contraste entre duas superfícies escuras satura perto de 1,4 por mais que se afaste os tons, e isso só aparece medindo.

Três pesos de texto, não cinco

Cada nível a mais é uma decisão que alguém vai tomar diferente do resto do time. Escala pequena é escala que se respeita.

O espaço vem da estrutura

O espaçamento entre blocos vem de uma coluna com gap, e não de margem em cada componente. Margem avulsa funciona entre dois vizinhos e cola quando alguém insere algo no meio.

Cores

Os valores abaixo são lidos do documento. Trocar o tema no seletor acima muda o que aparece aqui.

Contraste

Cada combinação de texto e fundo que o sistema realmente usa, com a razão calculada pela fórmula da WCAG 2.1. O mínimo para texto normal é 4,5.

Performance

As métricas que o Google usa para ranquear, medidas nesta página com PerformanceObserver, sem biblioteca. Os números mudam conforme você navega.

Componentes

Campo de valor

<campo-valor>

Guarda centavos em inteiro e preserva a posição do cursor ao reformatar. Digite no meio do valor para ver: o cursor continua depois do mesmo dígito.

123456 centavos

Por que centavos em inteiro

0.1 + 0.2 dá 0.30000000000000004 em ponto flutuante. Num sistema de cobrança essa diferença vira divergência de centavo no fechamento do dia. Dinheiro é contagem, não medida.

Campo de texto

.campo

O estado de erro muda a borda e marca aria-invalid. A borda vermelha sozinha não informa nada a quem usa leitor de tela.

Ficha

.ficha

Número grande com rótulo pequeno. A variante de atenção existe para quando o número exige ação, e não para toda ficha que muda.
